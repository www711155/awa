نظام حصر كميات الدفاع المدني - نموذج أولي

التشغيل:
1. فك الضغط عن الملف.
2. افتح index.html بالمتصفح (كروم أو إيدج) بنقرتين.
3. اضغط "جرّب مخططًا تجريبيًا" أو ارفع ملف DXF.

ملاحظات:
- يدعم حاليًا DXF النصي فقط. لملفات DWG احفظها DXF من أوتوكاد.
- الأسعار افتراضية للتجربة فعدّلها.
- يعمل بدون إنترنت (الخط العربي فقط يحتاج إنترنت، وله بديل تلقائي).
- الملف لا يرفع مخططاتك لأي خادم، كل المعالجة داخل المتصفح.
