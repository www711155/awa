حصر كميات مخططات الدفاع المدني (نموذج المرحلة 1)

التشغيل: فك الضغط مع إبقاء مجلد lib بجانب index.html، ثم افتح index.html في Chrome أو Edge.
قارئ PDF مضمّن ويعمل بدون إنترنت. الحصر بالذكاء الاصطناعي يحتاج إنترنت ومفتاح Anthropic API.

الحصر (اختر الطريقة من صفحة الرفع):
- 📖 مكتبة الرموز (الافتراضية): يقرأ رموز الجدول المرفق بالمخطط (Legend) من نصوص الـPDF تلقائيًا، أو بالذكاء الاصطناعي، أو تعرّفها أنت بالسحب (🎯) ثم يحصي كل ما يطابقها في المخطط ويستثني الجدول نفسه (🚫 لاستثناء أي منطقة). الرموز التي تعرّفها بالسحب تُحفظ في متصفحك وتُستخدم في المخططات القادمة (بنفس مقياس الورقة).
  اختبره بـ samples/sample-legend.pdf : المتوقع رشاش 7، كاشف دخان 4، نقطة نداء 3.
- 🔍 مطابقة تلقائية: يكتشف الرموز المتكررة في المخطط ويعرضها بصورها وأعدادها؛ تسمّي كل نوع مرة واحدة ثم «اعتماد».
- DXF: حصر آلي مباشر من البلوكات والطبقات (اختر وحدة الرسم قبل الرفع).
- بدون مفتاح: اضغط «🎯 تعلّم رمز بالسحب» وحدّد رمزًا واحدًا بمستطيل ضيق، فيجد كل الرموز المشابهة (نفس الحجم والاتجاه) في كل الصفحات.
- PDF أو صورة بالذكاء الاصطناعي: أدخل مفتاح API واضغط «حصر بالذكاء الاصطناعي» (يعمل تلقائيًا بعد الرفع إن كان المفتاح محفوظًا).
  تظهر علامات زرقاء على المخطط لكل عنصر؛ صحّحها بالنقر (إضافة) أو بزر الفأرة الأيمن (حذف).
- الجداول تبدأ فارغة؛ لا توجد بيانات افتراضية. زر «جرّب مخططًا تجريبيًا» يحمّل DXF تجريبي مدمج.
- المفتاح يُحفظ في متصفحك فقط. للإنتاج يُنقل الاستدعاء إلى خادم حتى لا يظهر المفتاح.

samples/sample-plan.pdf و samples/sample.dxf للتجربة. المكتبة: pdf.js (Apache 2.0).
