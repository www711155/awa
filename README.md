# نظام مؤسسة الأمان الرفيع

نظام مبيعات ومخزون ومحاسبة — ملف واحد (HTML/CSS/JS)، بلا خادم وبلا قاعدة بيانات خارجية.

## النشر على Vercel
1. ارفع هذا المجلد إلى مستودع جديد على GitHub (خطوات أدناه).
2. في vercel.com اختر **Add New → Project**، ثم اختر هذا المستودع، واضغط **Deploy** بلا أي إعداد إضافي.
3. سيعطيك Vercel رابطًا فوريًا بصيغة `اسم-المشروع.vercel.app`. يمكنك لاحقًا ربط نطاقك الخاص من Settings → Domains.

## الرفع إلى GitHub (من سطر الأوامر)
```bash
cd اسم-المجلد
git init
git add .
git commit -m "النسخة الأولى"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
أو ارفع الملفات مباشرة من واجهة GitHub: أنشئ مستودعًا جديدًا ثم اسحب الملفين إليه (Add file → Upload files).

## تنبيه مهم عن البيانات
البيانات (الفواتير والمنتجات والعملاء) تُحفظ داخل متصفح كل جهاز يفتح الرابط، وليست مشتركة بين الأجهزة أو المستخدمين. من يفتح الرابط من جهاز آخر يبدأ بنظام فارغ. لنقل البيانات بين الأجهزة استخدم "نسخ احتياطي واستعادة" داخل صفحة "المستخدمون والنسخ".

## المستخدمون الافتراضيون
عند أول تشغيل ستجد 5 حسابات جاهزة (مدير، محاسب، كاشير، مبيعات، مخزن) بكلمات مرور مؤقتة يجب تغييرها فور الدخول. غيّر كلمات المرور فورًا ولا تترك هذا الملف بكلمات المرور الافتراضية على مستودع عام.
